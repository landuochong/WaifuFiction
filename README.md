# 纸片舞伴

一个“真人动作驱动 2D 角色”的创作工作台原型。用户上传角色图和跳舞参考视频，再生成纸片舞伴预览。

## 本地体验

直接用浏览器打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8000
```

随后访问 `http://localhost:8000`。

目前默认角色的跳跃、左右摇摆和转身均采用完整动作关键帧播放，手臂和膝盖由每一帧直接绘制，不使用页面裁切伪骨骼。转身包含八个方向，并配有摆臂、屈膝和重心切换。真实的“视频动作 → 角色视频”迁移需要下一阶段接入外部生成模型或自建动作迁移服务。

## 项目结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 角色图、动作视频上传与预览工作台 |
| `styles.css` | 产品界面、默认纸片人和预设动作 |
| `app.js` | 文件选择、预览状态与动作预设控制 |
| `animation-frames/` | 跳跃、左右摇摆与八方向转身的透明动作帧 |
| `rig-parts/` | 头、躯干、骨盆、上下臂、上下腿等独立透明骨骼零件 |

## 开发约定

- 接入生成服务时，上传角色图和动作视频到后端，轮询任务状态，再将输出视频替换当前预览舞台。
- 页面适配手机与桌面，支持键盘焦点和减少动态效果的系统偏好。

## 验收清单

- 上传角色图，确认它会出现在预览舞台。
- 选择预设动作或上传视频，确认状态提示正确更新。
- 进入“自由控制四肢”，拖动肩、肘、髋、膝滑杆，确认父子关节能够独立旋转。
